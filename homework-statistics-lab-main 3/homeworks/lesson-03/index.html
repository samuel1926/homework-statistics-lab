01 / MATHEMATICAL SETUP

One process. Two different worlds.

For attacker a, each step i represents a separate system. The score is generated from an independent draw Xa,i. All increments use the same distribution, and different attackers are independent too.

01
ASYMMETRIC · PROBABILITY p

Bernoulli model

A penetration attempt contributes 1 on success, 0 on failure. The sum is a count of successful attempts.

X ∈ {0, 1}  ·  P(X = 1) = p
E[X] = p  ·  Var(X) = p(1 − p)
Sn ∼ Binomial(n, p)
POSITIVE DRIFT WHEN p > 0
02
SYMMETRIC · ZERO-MEAN

Rademacher model

An attempt contributes +1 or −1 equally often. This is a signed score, not a success count.

X ∈ {−1, +1}  ·  P(±1) = ½
E[X] = 0  ·  Var(X) = 1
Sn = 2B − n, B ∼ Bin(n, ½)

What “n systems, m attackers” means here. Each attacker performs n independent trials, one per system: there are m × n simulated draws for a fixed n. The simulation uses an idealized IID model: there is no shared vulnerability, learning between steps, or attacker coordination.

05 / LAW OF LARGE NUMBERS & VARIANCE

The average settles.
The total does not.

For IID increments with mean μ and variance σ², the average converges in probability to μ, while the three scalings have fundamentally different variance behavior.

i

Security interpretation is model-dependent. Bernoulli Sn counts successful compromises only if attempts are independent and have common probability p. Rademacher Sn is a signed net score; a negative value does not mean “negative compromises.” Real-world common-mode vulnerabilities, defense adaptation, and coordinated attackers violate these IID assumptions.

08 / MATHEMATICAL CONCLUSIONS

What stays. What changes.

The simulation illustrates exact variance identities and asymptotic theorems, but finite Monte Carlo results alone are not proofs.

01 / SUM

Totals spread out.

Var(Sn) = nσ² grows with n. In Bernoulli, its mean np grows too. In Rademacher, the mean stays zero but the spread grows as √n.

02 / LLN

Averages concentrate.

Var(Sn/n) = σ²/n → 0. Consequently Sn/n → μ in probability, by Chebyshev's inequality.

03 / CLT

Fluctuations become normal.

For Rademacher, Sn/√n ⇒ N(0,1). For Bernoulli with 0 < p < 1, first subtract np and divide by √(np(1−p)).

THE CENTRAL LESSON

Normalization decides the story.

The same IID random increments can yield a diverging sum, a stable average, or a non-degenerate normal limit. The number of attackers affects how many independent outcomes we observe — not the fundamental limit theorems for an individual path.
