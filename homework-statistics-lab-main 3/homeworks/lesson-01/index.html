FROM PART 01 TO PART 02

What changes when the curve is used for an Ethereum wallet?

The group law still computes a public point from a secret scalar. A real wallet adds secure entropy, deterministic key derivation, public-key hashing and checksummed address formatting. The toy curve above demonstrates arithmetic; the wallet experiment below implements real secp256k1 operations on public test vectors.
