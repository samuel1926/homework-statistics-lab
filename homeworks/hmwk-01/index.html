01 / THE CURVE

A finite set of points

We work with y² ≡ x³ + 7 (mod 17). There are 17 finite solutions and one identity point 𝒪. Unlike a continuous elliptic-curve drawing, the plot contains only integer-coordinate solutions in 𝔽₁₇.

02 / THE GROUP LAW

Addition is algebraic

For P ≠ Q, use λ = (y₂ − y₁)(x₂ − x₁)⁻¹. For P = Q, use λ = 3x₁²(2y₁)⁻¹. Then x₃ = λ² − x₁ − x₂ and y₃ = λ(x₁ − x₃) − y₁, all modulo 17.

03 / SCALAR MULTIPLICATION

From k to Q = kG

Repeated addition computes G + ··· + G (k times). Double-and-add evaluates the same result using the binary representation of k, reducing the number of operations as k grows.

04 / DISCUSSION & CONCLUSIONS

One-way does not mean hash.

Which observations matter for public-key cryptography, and which belong to the theory of hash functions?

01 / CORE INSIGHT

Efficient forward map, hard inverse

Scalar multiplication Q = kG is deterministic and efficient. In real secp256k1, retrieving k from Q is believed computationally infeasible (the elliptic-curve discrete logarithm problem). Our 18-element toy group is trivially searchable, so it provides no security.

RELEVANT TO ECC
02 / GROUP STRUCTURE

Outputs are not independent draws

The sequence G, 2G, 3G, … follows a mathematical subgroup. If G has order n, then (k+n)G = kG. Over all k = 1, …, n, each subgroup element occurs exactly once, including 𝒪. x coordinates may repeat for P and −P.

RELEVANT TO ECC
03 / UNIFORMITY

Uniform scalars ≠ uniform coordinates

A uniformly chosen scalar modulo the order of G yields a uniform group element, but it does not make x and y independently uniform over 0, …, 16. Histograms depend on the subgroup and the chosen sample range.

INTERPRET CAREFULLY
04 / HASH COMPARISON

Avalanche is not an ECC requirement

Cryptographic hashes are normally evaluated for diffusion and avalanche-like behavior of their encoded output bits. A simple Hamming-distance test on point coordinates depends on the encoding and does not establish ECDLP hardness or hash-like security.

MORE NATURAL FOR HASHES
