EXERCISE / 01

Riemann vs. Lebesgue integration

Partition the domain into intervals, or partition the range into value bands and measure their preimages. Watch the estimators converge—and understand why pathological functions need more than sampling.

xAPPROACH A

Riemann · domain-first

IR,N = Σi=0N−1 f(a+(i+½)Δx) Δx

Split [a,b] into N subintervals and evaluate each midpoint. Efficient for smooth, bounded functions, but the existence of a limit is not automatic.

Δx = (b−a)/NO(N) evaluations
yAPPROACH B

Lebesgue · range-first

IL,B ≈ Σj yj · μ(f−1(Vj))

Split the values into B bands, compute the measure of all input points mapping into each band, and weight each band by its representative height.

Vj = [yj, yj+1)Exact/measured preimages
ⓘ
What the experiment actually compares. Midpoint quadrature is a Riemann-inspired approximation. The range method uses analytically derived preimage measures for these selected functions; for arbitrary functions, computing preimages can be expensive. Numerical sums alone do not prove Riemann or Lebesgue integrability.

Mathematical notes · pathological functions & the difference between algorithms and definitions +

Dirichlet: χℚ(x) = 1 for rationals and 0 for irrationals. Every interval has infimum 0 and supremum 1, so every lower Darboux sum is 0 and every upper sum is 1. Thus no Riemann integral exists. The rationals are countable and have Lebesgue measure 0, hence ∫χℚ dμ = 0. All uniform midpoints are rational; obtaining 1 numerically is not evidence of Riemann integrability.

Thomae: T(p/q)=1/q for reduced rationals, T(irrational)=0. It is continuous at irrational points and discontinuous at rational points; the discontinuities form a measure-zero set. Since T is bounded, Lebesgue's criterion implies Riemann integrability, and the integral equals 0. The code also constructs a certified upper bound on its upper Darboux sum by enumerating reduced rationals with q ≤ Q and bounding all remaining heights by 1/(Q+1).

Unbounded x−1/2: the classical proper Riemann definition on the closed interval does not apply at x=0. The improper limit limε→0+∫ε1x−1/2dx = 2 is finite and equals its Lebesgue integral. The range-space estimator truncates at x=1/B², and explicitly reports the missing tail 2/B.

∑WHY THE SERIES WORKS

A convergent expansion

Φ(z) = ½ + (1/√2π) Σk=0∞ (−1)k z2k+1 / [2k k! (2k+1)]

Since the exponential's power series converges uniformly on any bounded interval, we may integrate term by term. With large |z|, alternating terms become huge before cancelling, making direct floating-point summation numerically fragile.

∫LIOUVILLE'S THEOREM

Why no elementary antiderivative?

Liouville's theorem on elementary integration constrains possible antiderivatives of elementary functions. In the exponential case, an elementary antiderivative of e−x² would require a rational function R satisfying R′ − 2xR = 1. No such rational R exists: poles are impossible, and no polynomial can satisfy the identity.

We therefore introduce erf as an exactly defined special function. Computers still need algorithms to evaluate it numerically.

Practical conclusion. Simpson's method usually reaches high precision with relatively few panels; the Taylor series is accurate near the center but can suffer cancellation in the tails. The fixed-cost erf approximation is fast but has a bounded approximation error. Production libraries such as SciPy use carefully designed specialized algorithms, including strategies that avoid tail cancellation.
RESEARCH NOTES

What we can conclude

Definitions, error estimates, and performance need to be interpreted together—not reduced to a single numerical score.

01 / CORRECTNESS

Equality of integrals

Every bounded Riemann-integrable function on a compact interval is Lebesgue-integrable, with the same integral. Dirichlet's function breaks Riemann integrability but has Lebesgue integral zero; Thomae's function has both integrals equal to zero.

02 / ACCURACY

Not all errors are the same

Quadrature error depends on the input partition, while range quantization error depends on the value partition. For the unbounded example, a positive truncation tail remains; it is deliberately not hidden in the reported estimate.

03 / EFFICIENCY

Cost depends on available structure

Midpoint, trapezoid and Simpson use a number of function evaluations proportional to their partition count. Exact level-set measures are cheap for simple or invertible functions, but potentially hard to obtain for generic functions.
